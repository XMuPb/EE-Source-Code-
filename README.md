# Open Source Release

## About This Project

After being away from the project and modding for approximately a year, I have decided to officially release the **full source code** of this project as open source.

This project has been an important part of my modding journey, and rather than leaving the code inactive, I would like to give other developers and modders the opportunity to continue working on it, improve it, learn from it, or take the project in a completely new direction.

The repository contains the **full source code** of the project.

## Why Is This Being Open Sourced?

Im gonna be gone for a year and currently do not have the time or availability to continue actively maintaining the project.

Instead of allowing the project to remain abandoned, I decided that making the source code publicly available would be the best way to give it a future.

If you are interested in the project, you are welcome to:

* Continue development
* Fix bugs and compatibility issues
* Add new features
* Improve existing systems
* Learn from the source code
* Create your own version or continuation
* Contribute improvements back to the project

## Current Status

⚠️ **Important:** This project is no longer actively maintained by me.

The source code is being released as-is. Some systems may require updates, fixes, or modernization depending on the current game version, modding APIs, dependencies, or development environment.

I cannot guarantee that the current version will work perfectly with newer versions of the game or other mods.

## For Developers

The purpose of this repository is not only to preserve the project, but also to allow someone else to continue where I left off.

If you decide to work on the project, I strongly recommend going through the source code and understanding the existing architecture before making major changes.

You are free to experiment, improve the code, restructure systems, and continue development according to your own vision, subject to the license included with this repository.

## A Project Left Open

I spent a lot of time developing this project, and it would be unfortunate for the work to simply disappear because I am no longer actively working on it.

By releasing the source code, I hope someone in the community may pick it up and give it a new life.

Maybe you will fix something I never had time to fix.

Maybe you will add features I never thought of.

Maybe you will completely transform the project.

**That's the point of open source.**

## Thank You

Thank you to everyone who used, tested, supported, reported bugs, provided feedback, or contributed to this project during its development.

Even though I have been away for a long time, I appreciate everyone who was part of the project.

The project may no longer be actively maintained by me, but now the source is available for anyone who wants to continue the work.
